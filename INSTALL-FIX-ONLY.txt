LIBERTY'S SHADOWS 2.0.5 - FIX ONLY (NO ENHANCEMENTS)

The original night-shadow repair using the current 2.0.5 shared core.
This edition does not enable extra dual-headlight, taillight, traffic-signal,
emergency or world-light shadows, vehicle fallback, scenery blending or the
experimental pole changes. It contains no replacement shaders or map assets.

INSTALLATION
Close GTA IV. Back up your existing mod INI, then copy the plugins folder into
the game folder and replace the existing Liberty's Shadows ASI and INI.
Keep FusionFix and its normal requirements installed. Enable the game's
Night Shadows and Shadow Quality settings.

Use either this edition or the full edition. They share the same plugin name;
do not install duplicate ASI copies under other names or folders.

UPGRADING FROM THE FULL EDITION
This package does not undo shader or map files installed by the full edition.
Restore those from your pre-install backup to return to your previous shader
setup. Do not delete your entire update folder or other mods' shader files.
The supplied INI disables the enhanced features even if those files remain.

SETTINGS AND SUPPORT
Enabled=0 turns off the fix after restart. The preset menu is hidden for this
edition. Leave Preset=Low and the enhancement switches at 0 for fix-only play.
For a support report, set Logging=1, restart, reproduce the issue and attach
plugins/OnyxOak.ExtraNightShadows.log with your game/FusionFix information.
Hook-based compatibility does not guarantee every mod combination.
