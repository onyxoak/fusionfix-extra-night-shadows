LIBERTY'S SHADOWS 2.0.5 - SETTINGS GUIDE

INSTALLATION
Close GTA IV and back up your customized INI. Copy BOTH plugins and update
folders into the folder containing GTAIV.exe. Keep the ASI and paired shaders
from the same package together. Restart after editing the INI.

PRESETS
High enables the full supported feature set. Medium reduces added light
families; Low provides the core fixes with fewer extras. Choose in Graphics
or change Preset in LIBERTY_SHADOWS. Keep the game's shadow settings enabled.

CUSTOM SETTINGS
Set Preset=Custom before changing individual lighting features and reaches.
BasePreset supplies defaults for omitted fields; explicit values override it.
Read the comments above each setting. Keep each key once, use decimal dots,
and put comments on their own lines. Save the file as .ini, not .ini.txt.

CASTER CULLING
SUPPORT / ReceiverCasterCulling=1 enables conservative shadow-caster culling.
Set it to0 and restart to compare without it. If shadows disappear in reflected
or offscreen views, disable this option and report the location/camera angle.
This controls shadow-caster processing, not the lighting preset or illumination.

VEHICLE FALLBACK
VEHICLE_BOX_SHADOWS / Enabled=1 keeps fallback vehicle silhouettes when a
detailed shadow map is unavailable. Set0 and restart to disable the fallback.
CarsPerLight, LightsPerCar and MaxDistanceMetres are explained in the INI.
Special thanks to MrBulkinAleksey for the original implementation.

PERFORMANCE COMPARISONS
Compare the same parked view, time, weather, preset and graphics settings.
Traffic changes load; repeat the comparison and stop recording while measuring.
Busy nighttime areas can remain demanding. A gain in one view is not universal.

COMPATIBILITY AND SUPPORT
Requires a working FusionFix install and ASI loader. FusionFix5.1.2 with
Volumetric Lights2.00 has worked in testing. Integration relies on actual hooks
and bindings rather than a version-number cutoff; incompatible hook changes
or conflicting mods may still require an update.
For a report, set SUPPORT / Logging=1, restart and reproduce the issue.
Attach plugins/OnyxOak.ExtraNightShadows.log, preset, location and graphics mods.
Restore Logging=0 afterward. Leave profiling disabled for normal play.
