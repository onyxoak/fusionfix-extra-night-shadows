# Liberty's Shadows 2.0 private candidate

Austin / OnyxOak's independent CE lighting candidate, derived from the preserved CE 1.9 source. This is unfinished engineering work, not a public 2.0 release. See the C-drive project docs/STATUS.md and REQUIREMENTS-2.0.md for scope and evidence.

Build 13 smooths currently authenticated traffic-headlight ranking over 120 ms, removes the abrupt player-intersection tier for traffic beams, adds 35 percent incumbent preference for beams, and preserves closely ranked incumbent map ordinals. Player headlights and approaching world lamps do not acquire this smoothing delay. Build 12 adds current player/camera priority, conservative offscreen influence-volume retention, and an opt-in traced static-geometry collection/class-7 draw experiment. Native geometry samples are currently empty for class 7; universal wall blocking is not established.

The full candidate profile enables dual headlights, keyed native world eligibility, traffic and emergency features, model observation, and experimental geometry hooks. Model observation is not model-light promotion. Baked/emissive/corona-only sources still require researched dynamic reconstruction. Seven active maps and eight cache entries remain. Neither eligibility nor rendering counters prove universal simultaneous shadows.

Only the independent D-drive game is staged. Normal, optimized and historical reference installations stay protected. Shared profiles/settings are backed up before launches but remain shared. Austin decides public acceptance. Attribution and upstream licenses are preserved in ATTRIBUTION.md, LICENSE and external dependency directories. Original source metadata is preserved under reference/baseline-source-metadata.

Build 14 retains the build-13 allocator and moves the optional model observer return hook past native stack cleanup. Build-13 failures were captured at the return path with corrupted stack state; the changed hook reached gameplay. This short launch does not prove stable compatibility or intersection-flicker resolution.

Private build15 preserves retained native shadow-map ordinals before cache scheduling, removes cyclic pairwise ranking, and extends ranking history through slow frames while requiring current eligibility/identity/relevance. It remains uninstalled until the active author test ends. See BUILD-IDENTITY.json and evidence/build15-identity.json. Full requested feature coverage remains incomplete.
