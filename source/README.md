# Liberty's Shadows 2.0.6

GTA IV shadow fixes and enhancements by OnyxOak. This source corresponds to
the 2.0.6 player package. See BUILD.md for building and testing, and
CONFIGURATION-2.0.md for settings. Matching shader sources/rebuild tools are
in shader-source; install the paired shaders and INI from the player package.

Special thanks to MrBulkinAleksey for the original vehicle shadow-box fallback.
