# Liberty's Shadows2.0 standalone attribution clarification

Liberty's Shadows by OnyxOak is developed as a separately loaded lighting/shadow ASI with its own implementation and configuration. FusionFix is optional on the supported native backend; supported FusionFix installations can coexist through separately authenticated adapters. This describes a runtime dependency and does not claim that all implementation code is original.

Historical version and credit wording describes the original upstream modification and remains available. SafetyHook and Zydis retain their dependency notices/licenses. Candidate71 adds native traffic-pool authentication without copying FusionFix's pool expansion or changing pool capacity. The implementation verifies Rockstar's original pool function; it retains existing traffic source identity, destruction, clock and collision guards.
