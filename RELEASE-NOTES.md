# 1.1 — Traffic Shadows and Distance Controls

I added a filter for traffic vehicles obstructing their own headlight shadow pass, plus separate headlight and lamppost shadow-reach sliders (Original or 5–75 feet; default 50 feet).

I observed improved traffic flicker in limited testing; the slider's visual benefit and performance are not yet measured. Internal build identifier: 21.

Manual installation requires the ASI AND three menu XML files in the runtime ZIP, plus the five INI entries in the README. No installer is included. Preserve your existing configuration. Menu-mod conflicts require merging.

Release/Win32 build and offline reach, budget and selection tests passed. Full corresponding source is attached. By OnyxOak, based on FusionFix by ThirteenAG and contributors, with coding assistance from OpenAI Codex.
