LIBERTY'S SHADOWS 2.0.4

More of Liberty City's existing lights cast moving shadows across people,
vehicles and the environment. High is the default. Low and Medium offer
lighter lighting presets; Custom lets you tune individual features.

INSTALL OR UPDATE
1. Close GTA IV. Back up your existing Liberty ASI and INI first.
2. Extract this ZIP beside GTAIV.exe, merging plugins and update.
3. Keep exactly one OnyxOak.ExtraNightShadows.asi. Remove any duplicate copy
   from the game root if the new one is in plugins.
4. Start the game. Keep stock Shadow Quality and Night Shadows enabled.
   Preset/feature changes marked for restart need a full game restart.

The included INI starts on High. Replacing it resets existing custom tuning;
copy your chosen values into the new documented INI if needed. See the included
TUNING-GUIDE for Custom setup, ranges, defaults and individual feature switches.
Choose Low or Medium before entering the world if performance is a concern.

COMPATIBILITY
Uses the existing supported GTA IV Complete Edition and ASI-loader setup.
Official FusionFix 5.1.1 is the established local test setup. This update also
corrects version-specific adapters for official 5.0.1 and 5.1.0; actual modpack
acceptance needs testing. Optional official VolumetricLights 2.00 is supported
through an authenticated adapter. Unknown modified builds may be refused safely.
FusionFix, VolumetricLights, DLSS and SISCO are not included in this archive.

HAVING ISSUES?
Send the full fresh plugins/OnyxOak.ExtraNightShadows.log, the exact FusionFix
version, and ASI filenames from both root and plugins. Startup failures write
useful details even with routine Logging=0. If asked for a normal session log,
set SUPPORT Logging=1, restart, reproduce, send the log, then return it to 0.
The new log can identify an unknown headlight conflict; it does not automatically
make every conflicting mod compatible. Back up files before changing your setup.

If RESC10/out-of-video-memory occurs, include renderer (DX9 or Vulkan/DXVK),
resolution, companion-mod versions, and whether the same spot fails after a
fresh launch with Liberty's Shadows disabled. Mod Medium does not reduce the
game's stock shadow resolution. A separate test one step lower in stock Shadow
Quality/Night Shadows can help identify resource pressure. No memory-limit
increase is required by this update, and this error is not claimed resolved.

KNOWN LIMITS
Busy nighttime scenes remain demanding. Shadow maps are limited, so some
transitions/pop-in remain. Individual lamp-pole shadows and fire shadows remain
unfinished. This build passed 141 offline checks; those are not a guarantee for
every modpack or long session. See CHANGELOG-2.0.4.txt.

ROLL BACK
With GTA IV closed, restore your saved previous ASI and INI. Shader payloads
are unchanged from 2.0.3. Attribution and license texts are included separately.
