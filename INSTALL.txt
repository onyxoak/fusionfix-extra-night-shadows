Liberty's Shadows 2.0.5
By OnyxOak

INSTALLATION
Requires GTA IV Complete Edition, an ASI loader and a working FusionFix install.
Close GTA IV and back up your customized OnyxOak.ExtraNightShadows.ini.
Copy BOTH plugins and update folders into the folder containing GTAIV.exe.
Replace the previous Liberty's Shadows files. Keep one copy of the ASI and use
the matching shaders from this package. No previous Liberty's Shadows release
is required. FusionFix, Volumetric Lights and DLSS-IV are separate downloads.

SETTINGS
High is the included preset; vehicle shadow fallback and conservative caster
culling are enabled. Choose a preset in Graphics or edit the commented INI.
Restart after changing the INI or any setting marked restart required.
To disable the new culling path, set ReceiverCasterCulling=0 under SUPPORT.
To disable vehicle fallback, set Enabled=0 under VEHICLE_BOX_SHADOWS.

COMPATIBILITY
Tested with FusionFix 5.1.2 and Volumetric Lights 2.00. Integration checks actual
hooks and bindings; unfamiliar version numbers alone do not block it. Different
calling conventions or conflicting required hooks can still prevent integration.
Compatibility with every game edition, future release or modpack is not guaranteed.

SUPPORT
Dense night scenes can remain demanding. Indoor flicker, some pop-in and pole
shadow issues remain under refinement. Reflected/offscreen shadows with culling
are still being checked; disable culling and restart if shadows disappear.
For a report, enable SUPPORT / Logging=1, restart and reproduce the problem.
Include plugins/OnyxOak.ExtraNightShadows.log, the preset, location, game build
and installed graphics mods. Return Logging=0 after troubleshooting.
Official downloads and support: https://www.nexusmods.com/gta4/mods/1459
