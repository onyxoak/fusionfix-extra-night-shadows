Liberty's Shadows 2.0.3
By OnyxOak

Dynamic shadows from headlights, taillights, traffic and emergency lights,
storefronts and supported city fixtures. High is the full lighting experience.

INSTALL / UPDATE
1. Close GTA IV. Back up the files you replace outside the game folder.
2. Install the complete official FusionFix package for Complete Edition.
3. Copy BOTH plugins and update from this ZIP beside the GTAIV.exe you launch.
   Replace previous Liberty's Shadows files. Remove duplicate older copies of
   OnyxOak.ExtraNightShadows.asi from other loader folders.
4. Keep Shadow Quality and Night Shadows above Off in the Graphics menu.
   Apply and confirm the game's Keep Settings prompt. Launch normally.
5. Reapply this package after a later FusionFix install replaces its shaders.

Tested: Complete Edition1.2.0.59, official FusionFix5.1.1, Vulkan/DXVK.
Requires FusionFix and its ordinary ASI loader. SISCO, DLSS-IV, a trainer,
ScriptHook, recording software and custom launchers are not required.
No source files, PDBs or local test helpers are needed by players.

QUALITY / CUSTOM SETTINGS
High is the default. For more performance, select Low or Medium in Graphics
before loading into the world. Restart after quality or On/Off changes.
Low: corrected headlights and streetlamp shadows.
Medium: Low plus supported traffic-signal and emergency-light shadows.
High: Medium plus dual headlights, taillights and expanded world lighting.
High reach defaults: street250ft, headlights50ft; brightness remains unchanged.
For individual options, set Preset=Custom in the INI and use the documented
controls beneath it. Back up your customized INI before future updates.

WHAT CHANGED
- Reduced repeated shadow processing and validation work; retained the native
  model-reference overflow protection from2.0.2.
- Added compatibility with official VolumetricLights v2.00 while preserving
  both mods' headlight/light-copy callbacks.
- Added scenery-shadow transitions near the existing application distance
  and brief retention for available static shadow maps.
- Updated physical lamp-pole shadow handling using existing selected maps.
- Corrected two identified low arcade light-source placements.
- Clear startup troubleshooting now keeps the actual compatibility error and
  explains safe disabling when an unsupported VolumetricLights setup is found.
High remains default. Normal logging, recording and profiling are OFF.
This is the exact candidate210 binary tested by OnyxOak, without a rebuild.

OPTIONAL VOLUMETRICLIGHTS
Official VolumetricLights v2.00 was tested running together with this build
and official FusionFix5.1.1. It is optional and NOT included in this ZIP.
https://github.com/RecklessGlue540/VolumetricLights/releases/tag/v2.00
Install its complete official package if wanted, with backups. This supports
that exact binary; unknown modified copies and other renderer hooks can still
conflict. A Project Lights bundle may contain a different version: check it.

HAVING ISSUES?
First check the launched folder and install BOTH package folders together.
Read plugins/OnyxOak.ExtraNightShadows.log for a startup failure; it records
fatal compatibility failures even when normal Logging=0.
If the log rejects VolumetricLights, close GTA IV and move VolumetricLights.asi
AND VolumetricLights.ini outside the entire GTA IV game folder, then restart.
Moving the ASI from plugins to the game root does not disable it. If the log
says VolumetricLights was accepted, a later check failed for another reason.
Do not bypass protections. Send the full log, exact FusionFix/VolumetricLights
versions and ASI lists from both the game root and plugins folders.

NOTES
Dense nighttime scenes remain demanding, especially on High. Optimization
continues. Some pole models, abrupt map replacements/pop-in, light cutouts
and other shadow artifacts can still need refinement. Fire-shadow coverage
is unfinished. This update does not promise every compatibility or crash fix.

REPORT / ROLLBACK
Use Nexus Bugs with one issue per ticket: versions, preset, other lighting
mods, location/time/weather, exact steps and a screenshot or short clip.
For performance reports include hardware, resolution and renderer.
https://www.nexusmods.com/gta4/mods/1459?tab=bugs
For detailed support only, set SUPPORT Logging=2 and restart, reproduce
briefly, then restore Logging=0. Diagnostic runs do not represent clean FPS.
To undo an update restore your backed-up ASI, INI and shaders together.
Off in the menu alone does not restore stock FusionFix comparison shaders.
